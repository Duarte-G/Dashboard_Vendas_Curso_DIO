# Dashboard de Vendas - Xbox Game Pass

## Sobre o Projeto
Este projeto consiste em um dashboard simples para visualização e análise de vendas de assinaturas do Xbox Game Pass. O dashboard permite acompanhar o desempenho de diferentes tipos de assinaturas oferecidas pela plataforma.

## Conteúdo
O dashboard apresenta:
- Vendas de assinaturas EA Play
- Vendas de assinaturas Minecraft
- Vendas de assinaturas Game Pass
- Valores totais em reais para cada categoria de assinatura

## Tecnologias Utilizadas
- Google Planilhas/Microsoft Excel

## Como Utilizar
1. Faça o download do arquivo .xlsx
2. Abra o arquivo em Microsoft Excel ou Google Planilhas
3. Navegue pelas diferentes abas para visualizar os dados

## Objetivo
Este dashboard foi criado para facilitar a visualização e análise do desempenho das vendas de diferentes planos de assinatura do Xbox Game Pass, permitindo uma tomada de decisão mais informada sobre estratégias de marketing e vendas.
